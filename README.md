# AsphIndex Releases

Public download channel for AsphIndex test and release builds.

## Latest preview

**Direct Windows installer:**

https://github.com/Asphroxia/AsphIndex-Releases/releases/download/preview/AsphIndex-Preview-Setup.exe

**Preview release page:**

https://github.com/Asphroxia/AsphIndex-Releases/releases/tag/preview

The `preview` tag is permanent. Each successful preview build replaces the assets behind that tag, so the direct installer URL stays the same while the application is updated.

Expected preview assets:

- `AsphIndex-Preview-Setup.exe`
- `asphindex-hub.exe`
- `asphindexd.exe`
- `SHA256SUMS.txt`
- `latest.json`

## Notes

This repository contains compiled distribution artifacts and release metadata only. The private AsphIndex source repository remains separate and is not mirrored here.

Preview builds may be unstable and are intended for testing before a normal versioned release is published.
